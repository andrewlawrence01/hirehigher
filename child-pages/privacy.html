Privacy & security

Hire Higher is committed to protecting the information you provide when using our website.

What we collect

Basic account details and the profile information you choose to add.

How you sign in

Sign-in and passwords are handled by Supabase Authentication.

Where it's stored

Account data and profile photos are stored with Supabase services.

Information we collect

When you create an account

  • First name
  • Last name
  • Email address

When you build your profile

  • Full name
  • Location
  • Biography
  • Profile photo

Account security

Hire Higher uses Supabase Authentication to manage user sign-in and account authentication.

Password authentication is handled through Supabase. Never share your password with anyone else.

Data storage

Account and profile information is stored using Supabase services.

Profile photos are stored using Supabase Storage.

Questions about privacy
